## From installation to your first game

<Steps>

1. **Set up the panel**

   Install Campfire with [Docker Compose](/Campfire/getting-started/) or a
   [Linux binary](/Campfire/binary-installation/). The panel manages accounts,
   permissions, configuration, and automation.

2. **Connect a game host**

   Add a [Spark](/Campfire/spark-agent/), the agent that runs game containers on
   a Linux host. Start with one machine and add more hosts when you need them.

3. **Choose a game and start playing**

   Import an [Ember](/Campfire/egg-compatibility/), the definition for installing
   and running a game, then create your [first server](/Campfire/first-server/).
   Supported Pterodactyl and Pelican Eggs can also be imported.

</Steps>
