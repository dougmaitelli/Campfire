## A home for your game servers

Campfire is a self-hosted panel for running games across Linux machines.
The panel manages accounts, permissions, and automation. A **Spark** agent on
each game host runs the containers. **Embers** define how each game is installed
and configured, including supported Pterodactyl and Pelican Egg imports.

Start with [Docker Compose](/Campfire/getting-started/) or a
[Linux binary](/Campfire/binary-installation/), then
[install your first game server](/Campfire/first-server/).

## Follow the game live

Stream game and installer logs and send commands from the
[console](/Campfire/console/). Give friends access to their servers through
[roles and memberships](/Campfire/authentication/).
